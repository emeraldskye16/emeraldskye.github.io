# B. Justification for Inclusion

I selected this artifact because it provides a strong foundation for demonstrating growth in software engineering. Several aspects of the original code made it an ideal candidate for enhancement:

- The architecture could be improved to better follow object‑oriented design principles.
- Several components were tightly coupled, making the code harder to maintain.
- Naming conventions and documentation were inconsistent.
- The project lacked modularity, limiting scalability.
- The structure did not fully support future enhancements planned for Milestones 3 and 4.

By enhancing this artifact, I demonstrate my ability to:

- Refactor and reorganize complex codebases  
- Apply software engineering best practices  
- Improve maintainability and readability  
- Strengthen architectural design  
- Prepare a project for multi‑stage enhancement across the capstone  

These improvements directly align with the CS 499 course outcomes related to professional software development, communication, and engineering design.

# C. Enhancement Details

The software design and engineering enhancement includes the following improvements:

### **1. Architectural Refactoring**
- Introduced clearer separation of concerns  
- Reorganized major components into logical modules  
- Improved class and function responsibilities  

### **2. Improved Naming Conventions**
- Updated variable, function, and class names for clarity  
- Ensured consistency across the entire project  

### **3. Enhanced Documentation**
- Added docstrings and inline comments  
- Created clearer descriptions of component behavior  
- Improved readability for future developers  

### **4. Increased Modularity**
- Broke large functions into smaller, reusable components  
- Reduced coupling between modules  
- Improved testability and maintainability  

### **5. Prepared for Future Enhancements**
- Structured the project to support algorithmic optimization (Milestone 3)  
- Added interfaces and patterns that support database integration (Milestone 4)  

These changes demonstrate professional‑quality software engineering and prepare the artifact for the remaining capstone milestones.
