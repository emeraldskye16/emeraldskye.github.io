The original version of the artifact contained several algorithmic inefficiencies, including:

This milestone focuses on addressing these issues through targeted algorithmic improvements.

# B. Justification for Inclusion

I selected this artifact for algorithmic enhancement because it contained clear opportunities to demonstrate growth in computational reasoning and performance optimization. Specifically:

- Several operations were implemented using brute‑force approaches.  
- Data structures were chosen for convenience rather than efficiency.  
- The project did not scale well with larger input sizes.  
- There were opportunities to reduce time complexity from O(n²) to O(n log n) or O(n).  
- The refactored architecture from Milestone 2 made algorithmic improvements easier to implement cleanly.

Enhancing this artifact demonstrates my ability to:

- Evaluate algorithmic trade‑offs  
- Improve runtime and memory efficiency  
- Select appropriate data structures  
- Apply computational thinking to real software problems  
- Strengthen the artifact for future database integration in Milestone 4  

These improvements directly align with the CS 499 course outcomes related to algorithmic design, problem‑solving, and professional computing practices.

# C. Enhancement Details

The algorithms and data structures enhancement includes the following improvements:

### **1. Replaced Inefficient Algorithms**
- Identified O(n²) operations and replaced them with more efficient alternatives  
- Introduced sorting, searching, or hashing techniques where appropriate  
- Reduced redundant computations  

### **2. Introduced More Appropriate Data Structures**
- Replaced lists with sets or dictionaries for faster lookup  
- Introduced trees, stacks, queues, or other structures where beneficial  
- Improved memory usage and access patterns  

### **3. Improved Runtime Performance**
- Reduced algorithmic bottlenecks  
- Optimized loops and conditional logic  
- Ensured scalability for larger datasets  

### **4. Enhanced Error Handling and Edge Case Coverage**
- Improved robustness of algorithmic operations  
- Added checks for invalid or unexpected input  
- Strengthened correctness and reliability  

### **5. Prepared for Database Integration**
- Structured data flow to support future SQL or NoSQL operations  
- Ensured algorithms could handle persistent or external data sources  

These changes demonstrate mastery of algorithmic principles and computational optimization.
