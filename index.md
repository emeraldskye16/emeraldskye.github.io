# Professional Self‑Assessment

Throughout the Computer Science program, I developed strengths in several key areas:

- **Software Engineering & Design:**  
  My CS330 lighthouse project taught me how sensitive graphics pipelines are to shader structure, file paths, and rendering logic. Enhancing this artifact strengthened my architectural design skills, debugging strategies, and understanding of object‑oriented graphics programming.

- **Algorithms & Data Structures:**  
  My CS340 dashboard enhancement required designing a reusable query builder, implementing caching, and optimizing MongoDB aggregation pipelines. This improved my algorithmic reasoning, data transformation skills, and ability to design scalable systems.

- **Databases & Data Engineering:**  
  Rebuilding my DAD220 SQL project from scratch taught me how critical schema design, referential integrity, and query optimization are for real‑world reporting. I reconstructed the dataset, normalized the schema, and implemented API‑ready SQL logic.

- **Security & Defensive Programming:**  
  Across all artifacts, I improved input validation, error handling, and safe query construction—especially in the dashboard and SQL enhancements.

- **Collaboration & Communication:**  
  Documenting enhancements, writing narratives, and producing a code review video strengthened my ability to communicate technical decisions clearly to diverse audiences.

Together, these experiences shaped my professional goals and values. This portfolio demonstrates the technical depth, adaptability, and problem‑solving mindset I bring to the field.
